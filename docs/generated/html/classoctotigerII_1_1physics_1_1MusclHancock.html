Detailed Description

template<typename System>
class octotigerII::physics::MusclHancock< System >

Dimensionally unsplit, second-order predictor/corrector for conservative systems.

Piecewise-linear reconstruction follows the MUSCL lineage of van Leer (1979). Face states are predicted by half of the full multidimensional flux divergence, then a shared face flux updates cells. The System adapter supplies states, fluxes, admissibility, and unit conversions.
