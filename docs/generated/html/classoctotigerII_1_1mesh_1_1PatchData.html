Detailed Description

template<typename State>
class octotigerII::mesh::PatchData< State >

Owning patch value used for temporary snapshots and standalone kernel tests.

Persistent distributed interiors live in storage::StoragePartition instead. Values use MeshLayout indexing; this type may include ghosts when used in tests.
