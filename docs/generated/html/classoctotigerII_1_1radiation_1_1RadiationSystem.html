Detailed Description

Transport adapter whose state stores E and the physical radiative flux F.

E has units erg/cm³; F has units erg/(cm² s). Conversion to F/c occurs only at the calculation interface and always uses physical c. The reduced speed ĉ changes propagation, not the stored flux units or the realizability bound.
