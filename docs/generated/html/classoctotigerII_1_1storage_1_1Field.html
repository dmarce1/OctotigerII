Detailed Description

template<typename T>
class octotigerII::storage::Field< T >

Named scalar column distributed over a shared PartitionSet.

Capacity is independent per partition and bank count is configurable. A replacement allocation receives a fresh field ID. Old fields survive until retire() or destruction of the last partition handle; this is not an in-place resize API. Application stage publication remains a Runtime responsibility.
