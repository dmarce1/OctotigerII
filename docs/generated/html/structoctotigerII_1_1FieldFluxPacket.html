Detailed Description

template<class State>
class octotigerII::FieldFluxPacket< State >

Flux values with geometry and a physical time interval.

These are fluxes, not time-integrated corrections. A future AMR driver would need to integrate and reconcile them; this type alone does not perform refluxing.
