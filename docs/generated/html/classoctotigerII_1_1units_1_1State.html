Detailed Description

template<typename... Q>
class octotigerII::units::State< Q >

Tuple of quantities with independently checked physical dimensions.

get<I>() is compile-time indexing; operator[] exists only for homogeneous types. Named accessors follow the field ordering declared by each physics adapter. Arithmetic acts componentwise; multiplying by a quantity changes all dimensions.
