Detailed Description

template<typename T>
class octotigerII::storage::FieldHandle< T >

Copyable typed address directory; copying it does not copy numerical data.

Local reads retain a bank allocation, remote reads return received buffers. The caller enforces immutable inputs and non-overlapping writers. Low-level buffers are writable; this interface does not implement stage scheduling.
